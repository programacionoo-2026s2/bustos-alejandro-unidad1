 Tarea de clase 2: Permisos estilo UNIX con Iota

Descripción
Programa en Go que implementa un sistema de gestión de permisos al estilo UNIX usando tipos personalizados, constantes con `iota` (`Ejecutar`, `Escribir`, `Leer`), la función `describir` con operadores de bits y operadores de asignación avanzada (`|=`, `&^=`).

Ejecución
```bash
go run permisos.go
